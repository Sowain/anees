# أنيس

منصة عائلية لتعلّم المنهج السعودي: الطفل يلعب فيفهم، وولي الأمر يسنده بدليل واضح.

هذا المستودع هو المنزل الجديد لأنيس. أرشيف الملف الواحد القديم يبقى في مكانه دون تعديل — **لا نلمسه بعد اليوم**.

## المنتج

- **حسابات واشتراك** — دروس المنهج مجانية للأبد. الباقة العائلية (٣٩ ر.س/شهر أو ٢٩٩/سنة) تحفظ التقدم عبر الأجهزة وتضيف ملفات الأبناء ولوحة ولي الأمر.
- **صفحات لا ملف واحد** — هبوط، أسعار، دخول، لوحة ولي الأمر، شاشة «من يتعلم»، الدروس، محرّك الدرس.
- **محرّك الدرس** — افتتاح، معرفة سابقة، شرح، عرض، نموذج، تدريب، تحقق، إغلاق. ترتيب الدروس كما هو.

## مبادئ لا تُمس

1. المنهج الرسمي مجاني للأبد.
2. لا مقارنة بين الأطفال.
3. المكافأة تُكسب بالتعلم لا بالدفع.
4. الطفل بلا بيانات هوية.
5. بلا إعلانات.
