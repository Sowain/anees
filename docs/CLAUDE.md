# أنيس — دستور الصناعة

يُقرأ قبل إضافة أي درس أو شاشة. شقيق [دستور العلامة](./brand-constitution.md) و[منهجية الدرس](./lesson-methodology.md).

> **العمارة الحالية:** تطبيق متعدد الصفحات (حسابات واشتراك)، لا ملف `index.html` الواحد.
> أرشيف الملف الواحد يبقى في مستودع `lefa` **ولا يُلمس أبدًا**.

## المنتج

أنيس منصة عائلية سعودية: الطفل يتعلم بخطوات صغيرة تُلعب، وولي الأمر يسنده بدليل واضح.

- الدروس مجانية للأبد. الاشتراك للأسرة: تقدم يتبع الطفل، ملفات أبناء، لوحة ولي أمر.
- محرّك الدرس ثابت: افتتاح → معرفة سابقة → شرح → عرض → نموذج → تدريب → تحقق → إغلاق.
- التحسينات الثلاث داخل الخطوات لا فوقها: نزول طبقة عند غلط التحقق، إغلاق يسمّي اللفّة الجاية، تدريب بسقالة تختفي.
- عند بناء الدرس أطلق منهجية الصف (١–٣ أو ٤–٦ أو ٧–٩ أو ١٠–١٢) ثم خصوصية المادة. التفصيل في [lesson-methodology.md](./lesson-methodology.md).
- صفحات الطالب (فهرس الدروس، محرّك الدرس، من يتعلم): ورق كريمي، IBM Plex Sans Arabic، فيروز `#1f5c56`.
- صفحات ولي الأمر (الأسرة، الأدلة، عدة الصبر): مكتب هادئ، نفس الألوان، خطاب بالغ.

## المبادئ التربوية

1. الكلمة الصعبة تُشرح بلمسة داخل الجملة.
2. لوحة العرض تُلعب لا تُشاهد — خصوصًا الصفوف ١–٣.
3. الحوار يُعرض محادثةً لا نصًا ساكنًا.
4. كل حرف يُكتب لا يُقرأ فقط.
5. لسانان: عامية دافئة في التسويق، فصحى مبسطة في التعليم.
6. الأرقام هندية في الواجهة العربية، إلا رياضيات المسارات اللاتينية كما في الكتاب.
7. الدرس مربوط بالكتاب، ولكل درس دليل: ماذا / كيف / أخطاء طبيعية / ملاحظة صبر.
8. التدريب يُختم بنجاح. المكافأة تُكسب بالتعلم لا بالدفع.
9. الطفل يُقارن بنفسه فقط. لا لوحة صدارة في أي شاشة.
10. الرياضيات: محسوس ثم مصوّر ثم مجرد.
11. الصوت قبل اسم الحرف.
12. الملاءمة الثقافية شرط قبول: أسرة سعودية مسلمة. لا خنزير ولا معازف ولا تمثيل أنبياء.
13. لا درس يبدأ من الصفر إن أمكن استرجاع سابق.
14. التعلم لا يحتاج هوية. الطفل: اسم أول وصورة رمزية فقط.

## الاشتراك

باقتان لا أكثر، والحد الفاصل التقدم لا الدروس:

| | مجاني للأبد | عائلي |
|---|---|---|
| الدروس | كاملة | كاملة |
| التقدم | على الجهاز | يتبع الطفل |
| الأبناء | واحد على الجهاز | حتى ستة تحت حساب |
| لوحة ولي الأمر | الأدلة ظاهرة | التقدم محفوظ لكل ابن |

سعر واحد للأسرة: ٣٩ ر.س / شهر أو ٢٩٩ ر.س / سنة. لا سعر لكل طفل.

بوابة الدفع (مدى · Apple Pay · STC Pay) تُربط عند الإطلاق. المعاينة تفعّل الباقة على الحساب مباشرة بلا بطاقة.

## ما لا يُبنى الآن

- فيديو داخل الدرس.
- العودة إلى ملف HTML واحد.
- لمس مستودع `lefa`.
- لوحة صدارة أو مقارنة بين أطفال.
- إعلانات أو بيع ملصقات للطفل.
- بيانات هوية على الطفل.
